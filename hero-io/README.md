# Hero IO

# Description
Hero IO is a web application built using React. It displays trending and featured apps with detailed information for each app. The project focuses on providing a modern and user-friendly interface with smooth navigation and responsive design. It includes a responsive navbar with a hamburger menu using lucide-react icons.

# Technologies Used
- React
- React Router DOM
- React Icons
- Lucide React
- React Toastify
- Tailwind CSS
- PostCSS
- Autoprefixer
- React Scripts
- Web Vitals
- Testing Library (Jest, React Testing Library)
